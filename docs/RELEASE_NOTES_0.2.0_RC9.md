## 当前行为

- 剂量及累计剂量固定使用 mGy/mSv，速率固定使用 mGy/h、mSv/h；不提供集成或卡片单位选择项，不改变报文原值的物理量级。
- 不再创建或加载旧 `_micro` 伴随实体。旧注册项和历史保留，旧实体可能显示不可用；不会将旧微单位历史改成 m 单位，也不会自动合并到原始实体。
- 根据设备本次实际返回片段形成 1024、2048、4096 道候选。旧手动道数配置不再控制组帧；实体、卡片、存档和 CSV 共用实际点数和长度判定信息。
- 总道数没有线上声明或 EOF：`inferred` 表示推断，`observed` 表示观测依据，不是设备型号能力认证。内部缺洞、冲突不发布，尾片缺失与短谱可能无法区分。
- 只读设备状态与 41 项 A6 校准字段不依赖设备控制开关；协处理器固件为默认启用的普通 sensor，尊重用户手动禁用。
- 普通仪表盘可选择历史谱图，ROI、数据游标和缩放状态持久化；Ctrl+滚轮横向缩放。
