# KC761x 0.2.0

最低 Home Assistant 版本：**2026.7.0**。本版本基于已验收的 rc9 实现，由维护者明确授权以 `0.2.0` 正式版发布。是否已公开发布以 GitHub Release 为准；版本号不代表全部硬件已经验证，协议档案继续标记 `hardware_verified=false`。

## 功能与修复

- 剂量和累计剂量固定使用 mGy/mSv，速率固定使用 mGy/h、mSv/h；不提供单位选择项。旧 `_micro` 伴随实体停止加载，原始实体标识、旧注册记录和 Recorder 历史保留，不自动删除、换算或合并历史。
- 谱图实体、卡片、存档和 CSV 使用本次实际接收的点数，软件支持 1024/2048/4096 道候选，不再要求手动配置道数；长度判断保留观测或推断依据。
- 提供 TCP/BLE 配置、只读设备状态、41 项 A6 校准字段、脱敏诊断及有界谱图存档。
- 卡片在普通仪表盘中选择历史谱图，保留 ROI、数据游标和视窗状态。能量轴默认及复位从 0 keV 开始，手动缩小可回到实际 CH0，原始标定与数据不变。
- Ctrl+滚轮横向、Shift+滚轮纵向均围绕光标缩放，双击绘图区复位双轴；纵轴刻度限制显示长度，不降低原始数据或 CSV 精度。
- 采谱忙态不再锁住 Configure，诊断默认关闭并保留高级入口。自动加载地址包含卡片内容指纹，完整刷新即可加载更新，无需重新添加卡片。
- 修复损坏存档/索引恢复、前端异步生命周期与计时器、写前连接身份核验、状态位并发、取消/重载资源释放和配置预检等 9 项审查问题。
- 综合覆盖率与独立分支覆盖率分别设至少 95% 门禁，另有 Ruff、JSON、编译、前端契约、Hassfest 和 HACS 检查。

## 升级与安全

升级前备份 Home Assistant 配置并记录原版本。安装后重启 Home Assistant，再完整刷新仪表盘，使组件与内容指纹生效；谱图卡自动注册，不必添加手动资源。

旧 `_micro` 实体显示不可用是预期行为，其旧历史仍可能可见。集成不迁移、改写或清理 Recorder 历史及实体注册记录。累计值可由设备清零，因此作为普通传感器发布，不声明 `total_increasing`。

新建及缺省配置关闭设备写入；升级保留既有显式控制和定时校时等选项，不会替用户关闭这些行为。“启用设备控制”与“启用清除辐射统计数据”仍为两层门禁，清空操作不可恢复。`0x64` 校准写入始终禁止。生产环境不应使用尚未完成实机验证的控制或清空操作。

## 验证边界与已知限制

- 第 4、5 项和最近卡片修改已经维护者验收。0.2.0 版本同步后的本地全量测试为 169 passed，独立分支 818/858（95.34%），综合覆盖率 97.49%；Ruff、JSON、编译、前端语法/契约及依赖检查通过。公开发布仍须检查新候选的远端 CI，不将 rc9 的 CI 结果作为新提交已通过的证明。
- 有限实机证据覆盖 TCP、BLE 完整 2048 点和 TCP 恢复、真实 Gamma 存档与同一 ID 的 CSV 一致性、固定单位新增 History，以及已授权测试或人工确认项目；不外推到其它设备。
- 实际 1024/4096 点设备、其它型号/固件及中子传感器尚未验证。A0/A1 没有总道数或结束字段，缺失尾片与短谱可能无法区分；内部缺洞或冲突的谱图不发布。
- A3/A4 自动上传流模式接收已验证；高计数率触发的 A1 自动谱模式未验证，是条件限制，不是已确认缺陷。A4 帧接收不代表已实现脉冲流或瀑布图。
- 稳定性按维护者调整的验收标准接受已有连续运行数日的情况；仍保留采样缺口，不宣称已采集完整连续 24 小时定时记录，不提升其它硬件的验证等级。
- 身份、并发、取消等防御性场景为离线替身验证。浏览器自动滚轮操作曾超时，本地真实 ECharts 自动化与最终人工验收分别记录。完整组件部署时一条采谱启动警告的条目归属仍未确认。
- `KI-AVG-001`：一台已验证设备的设备端 AVG 字段持续为零，需要实时读数时可启用原始读数实体。
- `KI-FE-001` 按维护者“review 无新缺陷证据”的标准关闭，根因未证实，有新证据再重新开放。
- 串口、科创云、区间谱、A4 脉冲流/瀑布图和校准写入不在本版本范围。

## 回滚与收录

此前已公开的版本为 `v0.2.0-rc.1`。需要回滚时可重新下载该版本并重启 Home Assistant，但它不包含 rc9 后续修正，不应把代码回退视为数据迁移回退；回滚后须重新核对配置、实体和卡片。既有部署备份及历史记录不自动删除或还原。

HACS 默认仓库收录是独立流程；发布 Release 或提交收录 PR 均不代表申请已经获准。申请合并前仍可按 README 使用自定义仓库安装。
