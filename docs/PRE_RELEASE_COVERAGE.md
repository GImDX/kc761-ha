# 发布前功能与实体补全

基线：`29c2fc35793c350d0a4451770836db5c943d60b4`，`0.2.0-rc.4`。

2026-09-06 用户接受以下实施方案。本文件区分已接受设计与已执行验证；未填写结果的门禁仍未完成。

## 范围与裁定

- 累计量原始单位由用户确认为 `mGy/mSv`；保留当前数值、单位和既有历史，撤回此前只改微单位标签的建议。保留手册/UI 矛盾，不提升为新实机物理量证据。
- 动态谱图支持 1024、2048、4096 道。A0/A1 没有总道数字段，按每个辐射通道显式配置道数；旧配置默认 2048，不根据首段、静默时间或计数值猜测结束。
- 原始实体 ID、设备信息页中的主型号/硬件/主固件，以及现有默认启用的协处理器固件 sensor 保留。
- 增加默认启用的 3 个状态 sensor、6 个状态 binary_sensor，以及每个已安装通道的谱图累积 binary_sensor；只读状态不依赖设备控制开关。
- A6 新增 34 个普通只读实体，与原有 7 个合计 41 个业务字段；数组按系数顺序展开，字段不丢入大块 JSON 属性。所有校准实体无长期统计 state class。
- 剂量显示提供原始/微单位选择；微单位为对应原始值乘 1000，不改变 Gy/Sv 物理量类别。协议、内部缓存、原始诊断保持原始值；CPS、累计时间、校准系数不换算。
- 单位切换先做真实 HA Recorder/长期统计隔离验证；同实体切换不安全时采用独立微单位实体，原始实体及历史保留。
- A4 脉冲流、0x64 校准写入、串口、科创云仍不实现；整体 `hardware_verified=false` 不变。
