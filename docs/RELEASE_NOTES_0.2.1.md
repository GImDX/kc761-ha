# KC761x 0.2.1

基于 `v0.2.0` 的维护版本，落实 [HACS 审查中的后续建议](https://github.com/hacs/default/pull/10776#pullrequestreview-5568628313)。最低 Home Assistant 版本仍为 **2026.7.0**。

## 修复

- 删除 KC761 配置项时，通过 `async_remove_entry` 在执行器中清理该配置项的 `.storage/kc761/<entry_id>/` 谱档案目录，包括快照、索引及遗留临时文件。
- 关闭旧档案对象并等待进行中的档案操作结束，防止迟到的保存任务在删除后重新创建目录；卸载失败时也会尝试停止残余协调器。
- 校验清理路径并拒绝越界或链接目录，保护其它配置项的档案；目录不存在可重复处理，其它文件系统错误会记录。
- 重载、禁用和重启仍保留谱档案。配置 schema、设备唯一标识及 Recorder 历史不变。

## 升级与使用

在 HACS 更新后重启 Home Assistant，并完整刷新仪表盘。组件、卡片与软件包版本统一为 `0.2.1`。

删除配置项将同时删除其本地谱档案，需要留存的谱图请提前导出。此前已经删除配置项所遗留的孤立目录不会被自动扫描或清除。

项目已获准加入 HACS 默认仓库。此次修复在集成仓库发布，无需重新提交默认仓库收录申请。

## 验证边界

相同清理实现已在隔离测试容器的临时目录中验证删除、重复删除、相邻目录保护和卸载保留，并对既有运行配置完成只读核验；没有通过删除用户现有配置项来测试。

发布仍要求同一提交的完整回归、综合与独立分支覆盖率不低于 95%、前端契约、Hassfest 及 HACS 验证通过。

`hardware_verified=false` 及默认关闭设备写入的策略保持不变，既有显式控制和定时选项按原配置保留。硬件与协议的未验证范围继续适用 [0.2.0 版本说明](https://github.com/GImDX/kc761-ha/blob/v0.2.0/docs/RELEASE_NOTES_0.2.0.md)，此次维护修复不提升硬件认证等级。
