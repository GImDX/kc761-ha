# 架构决策记录

日期：2026-08-10

状态说明：Accepted 已接受；Deferred 延后；Rejected 不采用；Proposed 待评审。

## D-001 单仓库、内部分层

状态：Accepted

决定：HACS 集成和协议实现位于同一 Git 仓库；协议实现作为 `custom_components/kc761/protocol/` 内的纯 Python 子包。

理由：

- HACS 要求一个仓库只管理一个集成，运行文件位于集成目录。
- 当前只有一个消费者，拆出 PyPI 包会增加版本、发布和安装失败面。
- 纯协议子包仍可脱离 HA 独立单测，保留未来抽取空间。

后果：首版只有一个 release 版本；协议层禁止引用 HA 类型。

## D-002 首版只支持局域网 TCP

状态：Accepted

决定：设备作为 TCP 服务端，HA 通过用户配置的 host/port 连接。上位机观察到的 7601 作为预填候选，而不是硬编码协议常量。

理由：局域网是手册明确支持的本地接口；BLE 服务 UUID、MTU 和丢包恢复未验证；云与串口不具备足够资料。

## D-003 首版严格只读

状态：Accepted

决定：首版不注册控制实体和写 action；不发送 0x62、0x63、0x64、0x66。

理由：设备允许多通信端同时操作，且写状态、校准和清除具有覆盖、互相干扰或不可恢复风险。当前没有 L 级实机证据。

## D-004 轮询为基线、推送为补充

状态：Accepted

决定：实时状态默认每 5 秒读取，设备信息每 60 秒读取；若设备已经自动上传，则被动解析并更新内存，但集成不修改自动上传状态。

理由：轮询行为可预测，不依赖设备全局设置；5 秒兼顾测量更新和 HA Recorder 负担；被动吞掉推送帧是维持 TCP 流同步的必要条件。

## D-005 完整谱图不进入实体状态

状态：Accepted

决定：不把 1024/2048/4096 道数组作为 sensor state/attributes，不周期写入 Recorder。

理由：数据量和更新频率不适合 HA 状态机，且当前总道数与传输完成条件仍有歧义。

后续：完成实机证据后评审按需返回和独立 Lovelace 卡片。

## D-006 DEVICE_ID 是唯一标识

状态：Accepted

决定：Config Entry 和 Device Registry 使用设备返回的 DEVICE_ID；IP/端口只属于可重新配置的连接信息。

理由：IP 会随 DHCP 或网络迁移变化，不能代表物理设备。重新配置必须验证新地址返回相同 DEVICE_ID。

## D-007 控制能力必须显式启用

状态：Accepted，适用于后续阶段

决定：低风险控制也默认不出现；未来只有用户显式启用、测试环境完成范围/ACK/读回验证后才创建。

校准写入和清除统计不继承普通控制授权，需要单独决策。

## D-008 原始资料保留在本地，Git 记录哈希与结论

状态：Accepted

决定：官方编程手册和五张上位机截图保留在开发机并由 `.gitignore` 排除；协议证据文档记录文件名、大小、SHA-256 和审阅结论。

理由：实现结论必须能追溯到确切资料版本，但厂商资料的公开再分发授权尚未确认。仅记录哈希既能固定证据身份，也避免把二进制资料永久写入未来 HACS 公共仓库历史。

后果：新开发机需要从获授权渠道单独取得原始资料；公开 README 不依赖这些文件才能理解或安装集成。

## D-009 不自动发现局域网设备

状态：Accepted for v1

决定：首版只提供手工 Config Flow，不声明 DHCP、mDNS、SSDP 自动发现。

理由：手册没有发现协议、服务广播或稳定主机名证据。使用未验证的端口扫描会增加网络噪声和误识别。

## D-010 BLE 延后

状态：Deferred

启用 BLE 前必须确认：

- 服务 UUID；
- HA 主机蓝牙能力和代理支持范围；
- MTU 至少 185、优选 507 的协商行为；
- 通知分片、丢包、重复和补读；
- BLE 自动上传对其它连接的影响；
- Config Entry 如何在 TCP/BLE 间保持同一 DEVICE_ID。

## D-011 串口与云不实现

状态：Rejected for current scope

决定：不根据上位机按钮猜测串口参数；不实现明文科创云协议或自建云兼容逻辑。

重新评审需要新的官方协议或真实设备证据，以及明确的用户需求。

## D-012 累计量发布受单位门禁

状态：Accepted

决定：累计剂量和累计剂量当量实体默认关闭；在表格、正文和上位机显示之间的单位矛盾解决前，不声明 state class 或稳定单位。

理由：错误倍率一旦进入 Recorder 长期统计，很难无损迁移。

## D-013 Git 与发布边界

状态：Accepted

决定：本地仓库初始分支为 `main`。本轮只建立本地 Git 和文档基线，不创建远端、不推送、不发布 HACS 版本。

后续提交到 GitHub 前，必须核对授权、仓库元数据、提交者 noreply 身份、CI 和源资料公开许可。
